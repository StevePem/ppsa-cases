# Case Digest: Personal Property Securities Act (Australia)

The Personal Property Securities Act (the **PPSA**) was enacted in Australia in 2009 and came into full operation in 2012.  It substantially reformed the law in Australia relating to security over personal property.

I have prepared a digest of cases that interpret or comment on the PPSA.  Please click [here](https://github.com/StevePem/ppsa-cases/raw/main/PPSA-cases.pdf) to download the current version of the digest.  

I regularly update the digest to add new cases as they are decided, so please check back from time to time.
